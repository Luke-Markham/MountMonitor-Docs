## Planned topics

- Identify whether the shop is using browser printing, a USB tag printer, or a configured print queue.
- Check printer power, loaded labels, closed print head, and the readiness indicator.
- Use Re-check Printer and reconnect using supported browser/device settings.
- Distinguish generating a preview from sending a print job.
- Check current tag selection, browser print destination, and the correct replacement tag after part changes.
- Collect the useful details for support if printing continues to fail.
