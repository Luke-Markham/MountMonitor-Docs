Use the jobs board to find one job or bring a group of work together. Combine filters to find, for example, active whitetail shoulder mounts from a particular period or jobs brought in by the same outfitter.

## Find one job

On the **Jobs** board, use the search box at the top right. Enter a job number, Mount ID, client surname, or words from the job or mount's notes. Select the job number to open the record.

Search works alongside filters. If a job is missing, check both the search box and your selected filters.

## Apply filters

1. On the **Jobs** board, select the **filter icon** at the top right.
2. Choose the details you want to match. Scroll inside the filter window to see the remaining options.
3. Select **Apply**.

To change the results, open the filters again, change your choices, and select **Apply**.

## Choose the right filters

| Filter | What it finds |
| --- | --- |
| **Species** and **Mount Type** | Jobs containing a mount with that combination, such as a whitetail shoulder mount. |
| **Service** | Jobs containing the selected service. |
| **Job Tags** | Jobs carrying every selected job tag. |
| **Mount & Service Tags** | Jobs containing a mount or service with any selected item tag. |
| **Stages** | Jobs with a mount at any selected stage. |
| **Payment Status** | Jobs with any selected payment status. |
| **Priority** | Jobs with any selected priority. |
| **Created** | Jobs created within the selected date range. |
| **Estimated Completed** | Jobs with an unfinished mount due within the selected date range. |
| **Payment Received** | Jobs with a payment received within the selected date range. Select a received-payment status first to enable it. |

**Created** and **Estimated Completed** are alternative date filters. Clear one before using the other. For **Payment Received**, choose a status such as **Deposit Received**, **Partially Paid**, or **Paid in Full** first.

### Match All and Match Any

**Job Tags** uses **Match All**. For example, **Active** plus **Fisher Ranch** finds jobs with both labels.

**Mount & Service Tags**, **Stages**, and **Payment Status** use **Match Any** within their own group. For example, selecting two stages finds jobs with a mount at either stage.

Choices across different filter groups narrow the results together. A job can contain several mounts or services, so open it to check the particular animals or items you need.

## Examples

### Find work from an outfitter

Select the outfitter's label under **Job Tags**, then select **Apply**. Add **Active** if you want only their active jobs. See [Tag jobs](/jobs/organize-jobs-with-tags) to add the label first.

### Find whitetail shoulder mounts from a period

Choose the appropriate whitetail entry in **Species**, **Shoulder** or your shop's equivalent in **Mount Type**, and the period under **Created**. Select **Apply**.

If you want a particular promotion within that work, also select its label under **Mount & Service Tags**. See [Tag mounts and services](/mounts-and-services/organize-mounts-with-tags).

### Find closed jobs

Under **Job Tags**, select **Closed** and deselect **Active**. Select **Apply**. Add a client surname in search if you are looking for a particular record.

## Clear filters and select jobs

Open the filters and select **Reset** to clear the filter choices. Clear the search box separately if you entered a search term. You can then apply a different set of filters.

Use a column heading to change the sort order and the page-size control at the bottom to show more rows. Tick the checkbox beside each job you want to work with, then check the selected count before choosing a bulk action.

After filtering, you can [add a job tag to several jobs](/jobs/organize-jobs-with-tags#add-the-same-tag-to-several-jobs) or [take one payment across several jobs](/payments/split-a-payment-across-jobs).
