Use client tags to group people or businesses you work with, such as outfitters, trade clients, or clients who came through a particular referral source. Reuse the same label on each relevant client, then filter the Clients board to find that group.

## Add a tag to a client

1. Open **Clients** and select the client's name.
2. Select **Edit Client**.
3. Scroll to **Tags** and select **Add Tag**.
4. Choose an existing tag. To make a new one, type its name, select **+ Create**, then confirm **Create**.
5. Select **Update Client** to save.

You can also add tags in the full **New Client** form before selecting **Create Client**. If you added the client through the shorter form while creating a job, open their client record afterwards and use **Edit Client**.

For example, create **Outfitters** once, then select that existing tag on the other outfitter records you want to group together. A client can have several tags.

## Find clients with a tag

1. On the **Clients** board, select the **filter icon** at the top right.
2. Under **Tags**, select the label you want to find.
3. Select **Apply**.

If you select several tags, the results include clients with any of those tags. For example, selecting **Outfitters** and **Trade Clients** finds clients in either group.

Other filters narrow that group further. You can combine a tag with **Has Outstanding Balance**, **Minimum Job Count**, **Total Spend**, **Priority**, or **Created**.

<Tip>
Check the existing client filters before creating a label. For example, **Has Outstanding Balance** already finds clients with money owing, so you do not need to keep an unpaid-client tag up to date yourself.
</Tip>

To clear the filter choices, open the filters and select **Reset**. Clear the search box separately if you entered a name, phone number, or email address.

## Remove a tag from a client

Open the client, select **Edit Client**, then select the **×** on the label in **Tags**. Select **Update Client** to save.

This removes the label from that client. The tag stays available for other client records.

## Client tags and job tags

Client tags belong to the client record. They are not automatically added to the client's jobs, mounts, or services.

Use [job tags](/jobs/organize-jobs-with-tags) when you want to group whole jobs on the Jobs board, such as jobs brought in through an outfitter. Use [mount and service tags](/mounts-and-services/organize-mounts-with-tags) for particular items within those jobs.

A client's tags do not close or reopen their jobs. The job's own **Active** and **Closed** tags control that. See [Active and closed jobs](/jobs/close-or-reopen-a-job).
